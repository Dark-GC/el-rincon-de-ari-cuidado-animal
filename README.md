# 🐾 El Rincón de Ari: Cuidado Animal

**El Rincón de Ari** es un sitio web educativo dedicado al **cuidado, mantenimiento y bienestar animal**, enfocado tanto en **mascotas** como en **animales de granja**.  
Su objetivo es promover una cultura de **responsabilidad, respeto y sostenibilidad** en el manejo animal, ofreciendo información clara, práctica y accesible.

🌱 Porque cuidar bien no es un lujo: es una obligación moral.

---

## 🌐 Sitio web en vivo

👉 **Visita el sitio aquí:**  
🔗 https://dark-gc.github.io/el-rincon-de-ari-cuidado-animal/

---

## 📌 ¿De qué trata este proyecto?

Este proyecto aborda temas fundamentales como:

- 🐶 Cuidado responsable de mascotas  
- 🐄 Buenas prácticas en ganadería  
- 🩺 Prevención de enfermedades animales  
- 🧼 Higiene, alimentación y manejo diario  
- 🌿 Bienestar animal y sostenibilidad  
- 🤝 Relación ética entre humanos y animales  

Todo el contenido está pensado para **familias, cuidadores, estudiantes y productores**, con un enfoque práctico y humano.

## 🛠️ Tecnologías utilizadas

Este sitio está construido con tecnologías web modernas y livianas:

- **HTML5** – estructura semántica optimizada para SEO  
- **CSS3** – diseño visual limpio, moderno y adaptable  
- **Bootstrap 5** – diseño responsive  
- **JavaScript** – interactividad (modo claro/oscuro, comentarios, navegación tipo libro)

## 🧭 Estructura del contenido

El sitio se organiza en entradas tipo blog:

1. **Consejos de cuidado animal**  
2. **Importancia del mantenimiento animal**  
3. **Beneficios del cuidado responsable**

## 🤍 Filosofía del proyecto

> Cuidar animales no es solo alimentarlos.

Este sitio promueve valores tradicionales como el **respeto**, la **responsabilidad** y el **trabajo bien hecho**, usando herramientas modernas para educar a las nuevas generaciones.
